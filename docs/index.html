Client-side desk mirroring on-chain math (1e18 WAD). Run forge test for the full engine — multi-market, skew funding, partial liquidations, BoundOracle.

Protocol surface

  • ClearingHouse — list markets, deposit, open/close, margin, liquidate
  • InsuranceFund — fee sink + bad-debt cover
  • BoundOracle — deviation + heartbeat guards
  • FundingLib — skew premium → capped rate
  • RiskLib / PositionLib — leverage, MMR, blend entry
